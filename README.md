# 🎬 Movies App  

A modern **Movies Web App** built with **Next.js, TypeScript, Tailwind CSS, Shadcn UI, Zustand, TanStack Query, and Axios**.  
The app allows users to **browse movies, view details, search, paginate, and add favorites**.  

---

## ✨ Features  

- 🔎 **Search Movies** – Find movies by title.  
- 📄 **Pagination** – Load more movies easily.  
- 📖 **Movie Details Page** – View detailed info about each movie.  
- ⭐ **Add to Favorites** – Save movies to your personal favorites list (stored in Zustand).  
- ⚡ **Optimized Data Fetching** – Using TanStack Query + Axios.  
- 🎨 **Modern UI** – Styled with Tailwind CSS and Shadcn components.  
- 🚀 **Blazing Fast** – Powered by Next.js with SSR/ISR.  

---

## 🛠️ Tech Stack  

- [Next.js](https://nextjs.org/) – React framework for SSR & routing  
- [TypeScript](https://www.typescriptlang.org/) – Static typing  
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework  
- [Shadcn UI](https://ui.shadcn.com/) – UI components  
- [Axios](https://axios-http.com/) – API requests  
- [TanStack Query](https://tanstack.com/query/latest) – Server state management  
- [Zustand](https://zustand-demo.pmnd.rs/) – Local state management
